# User Management System
A full-stack user management application with cursor-based pagination and real-time status updates.

## Architecture
- Frontend: React + Vite 
- Backend: Node.js + Express.js
- Database: PostgreSQL 

## Features

- Cursor-based pagination with sorting by ID or age
- Email-based user filtering
- Toggle user active status
- Health check endpoints for backend and database
